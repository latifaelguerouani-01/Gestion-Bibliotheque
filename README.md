# Gestion de Bibliothèque

Application web de gestion d'une bibliothèque développée dans le cadre du module Architecture JEE.

## Fonctionnalités
- Gestion des livres
- Gestion des auteurs
- Gestion des emprunts
- Gestion des retours

## Technologies
- Java 17
- JSP et Servlets
- Hibernate
- MySQL
- Maven
- Apache Tomcat
- Architecture MVC

## Installation
1. Cloner le repository GitHub.
2. Configurer la base de données MySQL.
3. Configurer la connexion dans `hibernate.cfg.xml`.
4. Importer le projet Maven dans IntelliJ IDEA.
5. Exécuter l'application sur Apache Tomcat.
